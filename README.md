# 夜汤 · Midnight Soup

中韩双语离线海龟汤推理游戏，包含用户提供的 20 份罪案悬疑故事，按《记号》至《完美证词》的原始顺序排列；中文汤面、汤底保留原文，配有韩文翻译、三级提示和预设问答。

## 运行

下载完整项目后，用现代浏览器打开 `index.html`。韩文入口为 `ko/index.html`，也可通过页面语言按钮切换。无需安装依赖或构建。

## 功能

- 案卷滚筒、拖拽翻阅及随机抽取
- 每案三份现场记录、三级提示及完整真相
- 证据板与推理手记
- 预设问答与推荐问题
- 动态背景及减少动态效果偏好支持

本项目使用本地预设问答，未接入实时 AI。手记和调查进度仅在当前页面会话内保留，刷新后清空。

图片、字体、样式和脚本均已嵌入 HTML。字体许可全文保留在 HTML 注释中。

中文版为 `index.html`，韩文版为 `ko/index.html`。每个页面均可单独离线运行；使用语言切换时，请保留这两个文件及其目录关系。

## 下载与解压

下载 ZIP 后请先完整解压，再打开入口文件，不要直接在压缩包内运行。

## 한국어

ZIP 파일을 먼저 모두 압축 해제한 후 `ko/index.html`을 여세요. 페이지의 언어 버튼으로 중국어와 한국어를 전환할 수 있습니다.
인터넷 없이도 범죄 미스터리 20편을 플레이할 수 있습니다. 질문에는 미리 준비된 답변이 제공되며, 실시간 AI는 연결되어 있지 않습니다.
메모와 조사 진행 상태는 현재 페이지에서만 유지되며 새로고침하면 삭제됩니다.

## 自制案件 / 나만의 사건

在案件选择区左下角点击“自制案件”，填写案件名称、汤面、汤底，可选填简介、难度和三级提示。保存后自动选中，点击“开始调查”即可游玩。再次打开按钮可编辑已保存的自制案件。

自制案件仅保存在当前浏览器，不会上传或公开；清除浏览器数据会删除。在线中韩文页共享同一浏览器存档；离线文件与在线网站的存档不互通。在线自制案件支持 AI 问答，提问时会将当前案件内容发送至 AI 服务；离线支持提示与揭晓真相。

사건 선택 화면 왼쪽 아래의 ‘나만의 사건 만들기’를 누르면 제목, 문제, 정답과 힌트를 작성할 수 있습니다. 저장한 사건은 바로 선택되며 다시 열어 수정할 수도 있습니다. 사건은 현재 브라우저에만 저장되고 공개되지 않습니다. 브라우저 데이터를 지우면 삭제됩니다. 직접 만든 사건도 온라인에서는 AI 문답을 지원합니다. 질문할 때 현재 사건 내용이 AI 서비스로 전송됩니다. 오프라인에서는 힌트와 정답 보기를 이용할 수 있습니다.

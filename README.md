# 夜汤 · Midnight Soup

中韩双语离线海龟汤推理游戏，包含 20 份案卷：5 份入门、10 份困难、5 份专家。

## 运行

下载完整项目后，用现代浏览器打开 `index.html`。韩文入口为 `ko/index.html`，也可通过页面语言按钮切换。无需安装依赖或构建。

## 功能

- 案卷滚筒、拖拽翻阅及随机抽取
- 每案三份现场记录、三级提示及完整真相
- 证据板与推理手记
- 预设问答与推荐问题
- 动态背景及减少动态效果偏好支持

本项目使用本地预设问答，未接入实时 AI。手记和调查进度仅在当前页面会话内保留，刷新后清空。

字体许可文件位于 `fonts/`，请随字体一同保留。

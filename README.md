# 夜汤 · Midnight Soup

中韩双语离线海龟汤推理游戏，包含用户提供的 20 份罪案悬疑故事，按《记号》至《完美证词》的原始顺序排列；中文汤面、汤底保留原文，配有韩文翻译、三级提示和预设问答。

## 运行

下载完整项目后，用现代浏览器打开 `index.html`。韩文入口为 `ko/index.html`，也可通过页面语言按钮切换。无需安装依赖或构建。

## 功能

- 案卷滚筒、拖拽翻阅及随机抽取
- 每案三份现场记录、三级提示及完整真相
- 证据板与推理手记
- 预设问答与推荐问题
- 动态背景及减少动态效果偏好支持

本项目使用本地预设问答，未接入实时 AI。手记和调查进度仅在当前页面会话内保留，刷新后清空。

图片、字体、样式和脚本均已嵌入 HTML。字体许可全文保留在 HTML 注释中。

中文版为 `index.html`，韩文版为 `ko/index.html`。每个页面均可单独离线运行；使用语言切换时，请保留这两个文件及其目录关系。

## 下载与解压

下载 ZIP 后请先完整解压，再打开入口文件，不要直接在压缩包内运行。

## 한국어

ZIP 파일을 먼저 모두 압축 해제한 후 `ko/index.html`을 여세요. 페이지의 언어 버튼으로 중국어와 한국어를 전환할 수 있습니다.

메모와 조사 진행 상태는 현재 페이지에서만 유지되며 새로고침하면 삭제됩니다.

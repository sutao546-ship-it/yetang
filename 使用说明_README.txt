夜汤 · 中韩双语离线版

1. 先完整解压 ZIP，不要直接在压缩包内打开。
2. 双击 index.html 打开中文版；韩文版为 ko/index.html。
3. 推荐使用电脑 Chrome 或 Edge。无需安装软件、无需联网。

包含 20 个故事（5 个新手、10 个困难、5 个专家）、滚筒拖拽和随机选择、调查记录与证据板、推理手记、圆角按键反馈、平移推近背景与动态灯光。
已移除雨、雷电和声音。

离线版使用预设问答，不调用 OpenAI。真实 AI 需要联网及服务端 API 密钥。
